Démarrer Pseudo-FEC

Outil du cabinet, 100 % local : aucune donnée ne quitte votre ordinateur. Aucune commande à taper, aucun droit administrateur nécessaire.

1

Installer Python (une seule fois)

Téléchargez « Windows installer (64-bit) » de Python 3.13 sur python.org/downloads/windows.

Dans l'installeur : cochez « Add python.exe to PATH », puis cliquez sur « Install Now ».

Déjà installé ? Passez à l'étape 2. Version minimale : Python 3.11.
2

Récupérer et décompresser le dossier Pseudo-FEC

Sur GitHub, bouton vert Code → Download ZIP, puis clic droit → « Extraire tout… ». Choisissez un emplacement simple, par exemple C:\Pseudo-FEC.

Avant d'extraire : clic droit sur le fichier ZIP → Propriétés → cochez « Débloquer » → OK. Cela évite l'avertissement de Windows sur le fichier de lancement.
3

Double-cliquer sur « Lancer-Pseudo-FEC »

Une fenêtre noire s'ouvre. La première fois, elle prépare l'application (1 à 3 minutes, connexion Internet nécessaire pour télécharger les composants). Ensuite, le lancement est immédiat et l'outil fonctionne hors ligne.

Votre navigateur s'ouvre sur l'application. Gardez la fenêtre noire ouverte pendant l'utilisation : c'est elle qui fait tourner l'outil. Le bouton « Quitter » de la page l'arrête proprement.

Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires puis Exécuter quand même. Le fichier n'est pas signé numériquement à ce stade du pilote.
4

Définir la phrase secrète du cabinet

À la première utilisation, saisissez la phrase secrète deux fois. Elle chiffre les tables de correspondance (les vrais noms). Elle n'est enregistrée nulle part : en cas de perte, les tables sont irrécupérables. Conservez-la dans le coffre du cabinet.

5

Essayer sans vos données : bouton « Aide et test »

En haut à droite de la page :

• Lancer la démo : crée un dossier fictif avec deux exercices déjà importés, sans aucune saisie préalable.
• Télécharger le FEC fictif : pour tester l'import par glisser-déposer.
• Auto-diagnostic : vérifie que tout fonctionne. Le bouton « Copier le rapport » donne un texte sans aucune donnée de dossier, à m'envoyer en cas de problème.
• Ouvrir le dossier des tables / des sorties dans l'Explorateur.

Comment ça se passe ensuite ?

A

Créer un dossier : un simple code

Aucun nom à saisir. Utilisez un code neutre (par exemple D2025-017), sans le nom du client.

B

Importer le FEC

Glissez le ou les FEC (un par exercice). L'outil contrôle les totaux, les dates et lit le SIREN dans le nom du fichier.

C

Valider les propositions

L'outil propose la société, ses dirigeants et associés, ses sociétés liées, ses clients, fournisseurs et salariés. Vous cochez ce qui doit être pseudonymisé et vous regroupez les variantes d'un même nom.

Questions fréquentes

« Python n'est pas installé » alors que je l'ai installé

Fermez la fenêtre, relancez l'installeur Python en choisissant « Modify », et vérifiez que « Add python.exe to PATH » est coché. Si Windows propose le Microsoft Store au lieu de lancer Python, désactivez les « alias d'exécution d'application » pour python.exe dans Paramètres → Applications.

L'installation des composants échoue

Vérifiez la connexion Internet (proxy d'entreprise, antivirus). Sans Internet : demandez le dossier wheels (composants fournis), déposez-le à côté de bootstrap.py et relancez : l'installation se fait alors hors ligne.

Le navigateur ne s'ouvre pas

Copiez l'adresse affichée dans la fenêtre noire (elle commence par http://127.0.0.1) dans la barre d'adresse du navigateur.

La page affiche « Session non autorisée »

Fermez l'onglet, fermez la fenêtre noire et relancez Lancer-Pseudo-FEC : l'adresse change à chaque lancement.

Où sont mes données ?

Tables chiffrées : %LOCALAPPDATA%\PseudoFEC\tables. Fichiers produits : Documents\PseudoFEC\sorties. Le bouton « Aide et test » les ouvre directement. Ne supprimez pas le dossier des tables : il contient la correspondance chiffrée nom réel ↔ pseudonyme.

Mettre à jour l'application

Remplacez le contenu du dossier par la nouvelle version (en conservant le dossier .venv s'il existe). Vos tables ne sont pas dans ce dossier : elles ne sont pas touchées.

Désinstaller

Supprimez le dossier Pseudo-FEC. Les tables restent dans %LOCALAPPDATA%\PseudoFEC tant que vous ne les supprimez pas vous-même.

Version pilote — ne l'utilisez pas encore sur des dossiers sensibles sans avoir lu les limites connues dans README.md.
