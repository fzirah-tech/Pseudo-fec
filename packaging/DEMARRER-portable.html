Démarrer Pseudo-FEC

Version portable : rien à installer, aucune connexion Internet, aucun droit administrateur. Toutes vos données restent sur cet ordinateur.

1

Débloquer puis décompresser l'archive

Clic droit sur le fichier .zip → Propriétés → cochez « Débloquer » → OK. Puis clic droit → Extraire tout…

Choisissez un emplacement court et local, par exemple C:\Pseudo-FEC (évitez le Bureau, OneDrive et les dossiers réseau).

2

Double-cliquer sur « Lancer-Pseudo-FEC »

Une fenêtre noire s'ouvre, puis votre navigateur affiche l'application. Gardez la fenêtre noire ouverte pendant l'utilisation : c'est elle qui fait tourner l'outil. Le bouton « Quitter » de la page l'arrête proprement.

Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même. Le fichier de lancement n'est pas signé numériquement à ce stade du pilote.
3

Définir la phrase secrète du cabinet

À la première utilisation, saisissez-la deux fois. Elle chiffre les tables de correspondance (les vrais noms) et n'est enregistrée nulle part : en cas de perte, les tables sont irrécupérables. Conservez-la dans le coffre du cabinet.

4

Essayer sans vos données : bouton « Aide et test »

• Lancer la démo : dossier fictif avec deux exercices déjà importés, sans aucune saisie préalable.
• Télécharger le FEC fictif : pour tester l'import par glisser-déposer.
• Auto-diagnostic puis « Copier le rapport » : texte sans aucune donnée de dossier, à transmettre en cas de problème.
• Ouvrir le dossier des tables / des sorties dans l'Explorateur.

Comment ça se passe ensuite ?

A

Créer un dossier : un simple code

Aucun nom à saisir. Utilisez un code neutre (par exemple D2025-017), sans le nom du client.

B

Importer le FEC

Glissez le ou les FEC (un par exercice). L'outil contrôle les totaux, les dates et lit le SIREN dans le nom du fichier.

C

Valider les propositions

L'outil propose la société, ses dirigeants et associés, ses sociétés liées, ses clients, fournisseurs et salariés. Vous cochez ce qui doit être pseudonymisé et vous regroupez les variantes d'un même nom.

Questions fréquentes

Rien ne s'affiche / la fenêtre se ferme aussitôt

Relancez Lancer-Pseudo-FEC et lisez le message dans la fenêtre noire. Si l'antivirus a mis un fichier en quarantaine, restaurez-le ou demandez à l'informatique d'autoriser le dossier Pseudo-FEC. Le dossier doit rester complet (ne déplacez pas le fichier de lancement seul).

Le navigateur ne s'ouvre pas

Copiez l'adresse affichée dans la fenêtre noire (elle commence par http://127.0.0.1) dans la barre d'adresse.

« Session non autorisée »

Fermez l'onglet et la fenêtre noire, puis relancez : l'adresse change à chaque lancement.

Où sont mes données ?

Tables chiffrées : %LOCALAPPDATA%\PseudoFEC\tables. Fichiers produits : Documents\PseudoFEC\sorties. Le bouton « Aide et test » les ouvre directement. Ne supprimez pas le dossier des tables.

Mettre à jour l'application

Fermez l'application, supprimez le dossier Pseudo-FEC, extrayez la nouvelle archive au même endroit. Vos tables ne sont pas dans ce dossier : elles ne sont pas touchées.

Que contient ce dossier ?

python : Python 3.13 officiel (Python Software Foundation), avec ses composants. app : l'application. INVENTAIRE-COMPOSANTS.txt : composants, versions et licences. VERSION.txt : version et empreintes.

Désinstaller

Supprimez le dossier Pseudo-FEC. Les tables restent dans %LOCALAPPDATA%\PseudoFEC jusqu'à ce que vous les supprimiez vous-même.
